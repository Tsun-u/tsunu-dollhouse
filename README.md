# 小屋娃娃屋

兒童版宗旨：給小朋友的數位娃娃屋，可以自由幫角色換衣服、布置房間，用第三人稱陪角色們過日常。

給小朋友玩的單機娃娃屋：三消換材料、工坊做點心、開咖啡廳賺錢、買家具佈置家裡，最多住四個自己捏的娃娃。朋友來家裡時在同一台平板輪流玩，不用連線、不用帳號。

線上玩：https://tsun-u.github.io/tsunu-dollhouse/

## 怎麼玩

- **娃娃**：第一次打開先捏一個娃娃（身體、膚色、髮型與髮色、五官與眼睛顏色、眼鏡、名字）。最多四個，隨時可以改。
- **家**：點娃娃選她，再點地板走過去、點沙發或床坐下、躺下睡覺；同一間房的娃娃可以揮手、抱抱、坐在一起、一起睡。點家具還能洗手刷牙（找另一個娃娃一起刷）、在爐台煮家常菜、餵狗、澆花、開燈，可以換色的家具能換布面顏色；點狗可以摸摸、餵飯、丟球。家具從倉庫點一下，再點地板放下去。
- **三消 → 工坊 → 商店街**：三消消掉的圖案變成材料，工坊把兩個一樣的東西合成一個更好的，做好的東西拿到店裡賣給客人。一開始有咖啡廳，存夠錢可以在商店街租店面開雜貨店、服飾店，每家店都能換裝潢；服飾店做好的衣服也可以收進衣櫃自己穿。每次隨機請一個娃娃顧店。
- **家具店**：買家具、衣服、蓋新房間，幫娃娃在的那間房換地板和壁紙。
- **衣櫃**：幫娃娃換衣服、換顏色；多出來的衣服可以賣掉。
- **存檔**：自動存在這台瀏覽器。「娃娃」分頁可以匯出成檔案、在別台裝置匯入；也可以登入 Google 存到雲端硬碟，再從別台取回（存在雲端硬碟裡只有這個遊戲看得到的隱藏資料夾）。

店只在遊戲打開時營業，關掉就打烊。

## 安裝成 APP

可以把娃娃屋放到桌面或主畫面，像 APP 一樣打開（存檔一樣在這台裝置的瀏覽器裡）：

- **Android／電腦的 Chrome、Edge**：打開網址後，從瀏覽器選單選「安裝應用程式」或「加到主畫面」。
- **iPhone／iPad**：用 Safari（iOS 16.4 以後其他瀏覽器也可以）打開網址，按「分享」→「加入主畫面」。

## 開發

```
python -m http.server 8790        # 在這個資料夾開，瀏覽器開 http://127.0.0.1:8790/
npm test
```

- `src/`：娃娃屋自己的程式（娃娃、捏人、家、衣櫃、咖啡廳時鐘、存檔與雲端備份）。
- `vendor/`、`assets/`：從另一個專案「阿宇小屋」匯出的兒童包（規則、畫面、骨架播放器、零件圖、內容表、素材），是產生出來的檔案，不要手改。`vendor/pack.json` 記著匯出自哪個版本。
