# 小屋娃娃屋

給小朋友玩的單機娃娃屋：三消換材料、工坊做點心、開咖啡廳賺錢、買家具佈置家裡，最多住四個自己捏的娃娃。朋友來家裡時在同一台平板輪流玩，不用連線、不用帳號。

線上玩：https://tsun-u.github.io/tsunu-dollhouse/

## 怎麼玩

- **娃娃**：第一次打開先捏一個娃娃（身體、膚色、髮型與髮色、五官與眼睛顏色、眼鏡、名字）。最多四個，隨時可以改。
- **家**：點娃娃選她，再點地板走過去、點沙發或床坐下；同一間房的娃娃可以揮手、抱抱、坐在一起、一起睡。家具從倉庫點一下，再點地板放下去。
- **三消 → 工坊 → 咖啡廳**：三消消掉的圖案變成材料，工坊把兩個一樣的東西合成一個更好的，做好的點心放在咖啡廳賣給客人。咖啡廳每次隨機請一個娃娃顧店。
- **家具店**：買家具、衣服、蓋新房間。
- **存檔**：自動存在這台瀏覽器。「娃娃」分頁可以匯出成檔案、在別台裝置匯入；也可以登入 Google 存到雲端硬碟，再從別台取回（存在雲端硬碟裡只有這個遊戲看得到的隱藏資料夾）。

咖啡廳只在遊戲打開時營業，關掉就打烊。

## 開發

```
python -m http.server 8790        # 在這個資料夾開，瀏覽器開 http://127.0.0.1:8790/
npm test
```

- `src/`：娃娃屋自己的程式（娃娃、捏人、家、衣櫃、咖啡廳時鐘、存檔與雲端備份）。
- `vendor/`、`assets/`：從另一個專案「阿宇小屋」匯出的兒童包（規則、畫面、骨架播放器、零件圖、內容表、素材），是產生出來的檔案，不要手改。`vendor/pack.json` 記著匯出自哪個版本。
